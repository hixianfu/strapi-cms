# 视频与答疑分类维护

此前视频和答疑使用 schema 中固定的枚举分类。现在改成独立分类记录，可以在后台新增、改名和排序。

## 操作流程

1. 更新代码后，重新构建并重启 Strapi 后台和前端。
2. 在后台「内容管理」中进入「视频分类」或「答疑分类」，填写内容语言、名称、网址别名、排序并保存。
3. 新增或编辑「视频」「常见问题」时，在「分类（category）」中选择相同内容语言的分类，保存并发布内容。
4. 前端导航和列表页会自动读取对应语言的分类，按排序和名称展示，无需在全局导航中再次选择。

分类会出现在桌面悬停菜单、移动端导航和栏目列表页侧栏。已配置但没有内容的分类也会显示，点击后显示空列表。

分类名称、语言、网址别名和排序统一在分类管理中维护。

## 升级旧数据

数据库迁移会在结构同步前将旧的视频和答疑分类值保存到 Strapi 核心设置中。启动时将按旧值和内容语言创建分类，并关联草稿和已发布内容；已由编辑人员选择分类的记录不会被覆盖。转换完成会记录完成状态，后续启动不再重复执行。

转换依赖升级前数据库中仍然存在旧分类列；若此前已删除旧列，无法从已删除数据恢复关联，需要在后台重新选择分类。

新增内容类型后，使用自定义角色的维护人员需要拥有对应分类的管理权限。前端使用自定义 API Token 或 Public 角色时，需要允许读取对应分类（find/findOne），以便读取关联的分类名称和别名。

## 已验证范围

前后端 TypeScript 检查、后台构建，以及分类查询、空分类导航和旧数据转换的自动化测试。旧数据转换测试使用模拟数据；真实数据库的升级与后台操作需要在运行环境验证。
